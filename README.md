# 🕹️ RAC Games: Nosso Multiverso de Games 💖

Bem-vindo ao **RAC Games**! Este repositório funciona como um "Hub Central" (um portal interativo) criado para organizar e centralizar todos os web games desenvolvidos como presente de aniversário de namoro. 

Em vez de enviar vários links soltos, este projeto cria a experiência de um verdadeiro "sistema operacional do casal", onde cada quadrado (card) leva para um minigame diferente, mantendo a mesma identidade visual romântica e moderna.

## 🎮 Jogos Disponíveis Atualmente

Neste hub, você encontra os links diretos para as aplicações hospedadas:

* 🏆 **[RAC Quiz](https://rainangramacho.github.io/rac-quizz/)**: Um jogo estilo Game Show com 15 perguntas personalizadas. O quão bem você realmente me conhece?
* 🧩 **[RAC Wordle](https://rainangramacho.github.io/rac-wordle/)**: Uma versão do clássico jogo de palavras (Termo), onde as respostas e dicas são inteiramente baseadas nas nossas memórias e histórias.
* 🔒 **Em breve...**: O Hub foi projetado para crescer! Há espaços bloqueados ("Em breve") que servem como uma promessa de que novos jogos e presentes digitais serão adicionados nos próximos aniversários.

## ✨ Destaques do Design

O portal foi construído para parecer um aplicativo nativo, focado em uma navegação fluida:

* **Glassmorphism:** Os cards flutuam sobre um fundo animado, utilizando desfoque (blur) e transparência para um efeito de vidro fosco.
* **Micro-interações:** Botões e ícones reagem ao *hover* (passar o mouse), dando vida à interface.
* **Totalmente Responsivo:** Perfeito para ser acessado tanto pelo celular da pessoa amada quanto por um computador.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído de forma limpa e leve, garantindo um carregamento instantâneo:

* **HTML5** (Estruturação semântica)
* **Tailwind CSS** (Via CDN para estilização rápida dos cards e tipografia)
* **CSS Customizado** (Animações de entrada em "cascata" e transições de fundo)

## 🚀 Como Utilizar / Deploy

Este é um projeto 100% *front-end* estático. 

Para colocar no ar, basta hospedar o arquivo `index.html` no **GitHub Pages** (ou Vercel/Netlify). Se você for adaptar este Hub para os seus próprios presentes, basta abrir o código HTML e alterar os atributos `href` das tags `<a>` para os links dos seus projetos hospedados.
